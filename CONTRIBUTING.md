# Contributing to Inbox

Inbox is provided as is. Issues and pull requests are welcome. We cannot
promise a response. By submitting a contribution, you agree to license it
under AGPL-3.0-or-later, the same licence as the program.

Install the runtime requirements and then run the tests in the same environment.

```sh
python -m pip install --require-hashes -r requirements.txt
python -m pip install -r requirements-dev.txt
python -m pytest -q
```
